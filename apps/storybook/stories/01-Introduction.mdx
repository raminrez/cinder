# هشتی Hashti Design System

Welcome to **Hashti Design System** ([hashti-storybook.raminrez.dev](https://hashti-storybook.raminrez.dev) · [hashti.raminrez.dev](https://hashti.raminrez.dev)).

Hashti is an enterprise-grade React component library inspired by the spatial elegance, structural harmony, and dignified hospitality of classical Persian architecture. Built on **React Aria Components (RAC 1.22.1)**, zero-runtime scoped CSS, and comprehensive architectural tokens, Hashti serves as the welcoming transitional threshold between complex underlying application logic and serene human experience.

---

## The Iranian Architectural Portal Concept

In traditional Persian vernacular architecture—prominent across Isfahan, Yazd, Kashan, and Shiraz—the **Hashti (هشتی)**, derived from the Persian word for eight (*hasht*, هشت), is a vaulted octagonal or polygonal transitional vestibule situated immediately behind the entrance portal (*Sar-Dar*).

```
[Public Realm / APIs] ──► [Sar-Dar Portal] ──► [Hashti Vestibule] ──► [Dalan Corridor] ──► [Hayat Sanctuary]
```

The Hashti is never a mere passageway; it is a **deliberate pause**. In the harsh desert climate, the Hashti provides immediate relief through thick adobe massing, a zenithal skylight (*hoor-noor* / هورنور) bathing the space in diffused soft light, and acoustic serenity that muffles external clamor.

### The Concentric Arch Geometry
The Hashti brand mark is constructed from **concentric arches** reflecting authentic Safavid and Seljuk masonry geometry:
- **Arch Pitch:** 32° ogival pointed arch angle, derived from classic Persian four-centered pointed vault drafting techniques.
- **Stroke Cadence:** Exact **16px** stroke weight on master display scales with a **14px** negative space clearance gap.
- **Transitional Threshold:** Every component acts as an intentional threshold that buffers raw data into legible, serene user interfaces.

## Modern Aesthetic: Zero Carbon Squareness

Hashti completely eliminates the rigid, utilitarian squareness of Carbon:
- **Pure Monochrome Foundation:** Obsidian Black (`#000000` / `#09090B`) and Chalk White (`#FFFFFF` / `#FAFAFA`) provide high-contrast, distraction-free typographic surfaces.
- **Architectural Glazes:** Accented by vibrant mineral pigments:
  - **Persian Turquoise** (`#0D9488` / `#14B8A6`): Symbolizing clarity, water, and reflection (*howz*).
  - **Isfahan Amber** (`#D97706` / `#F59E0B`): Warmth, illumination, and golden zenithal daylight.
  - **Terracotta Clay** (`#DC2626` / `#EF4444`): Earth, adobe massing, and decisive boundaries.
- **Subtle Organic Curves:** Soft rounded corners (10px control radius, 14px group radius, 18px overlay radius) replace sharp industrial boxes.

## Core Principles

### 1. WAI-ARIA & Universal Access (RAC 1.22.1)
Built on Adobe's **React Aria Components**, every interactive primitive guarantees full keyboard navigation, roving tabindex, escape stack management, screen reader announcements, and strict **WCAG 2.2 AAA** compliance (7:1 contrast on body copy).

### 2. Zero-Runtime Scoped CSS
No CSS-in-JS runtime overhead. Pre-compiled, ultra-lean CSS stylesheets bundle all component layouts, states (`[data-hovered]`, `[data-focused]`, `[data-pressed]`, `[data-invalid]`), and theme CSS variables into static CSS.

### 3. Compound Composition Ergonomics
Inspired by modern compound component architecture (such as HeroUI v3 and React Aria), Hashti components provide direct access to sub-parts (`Modal.Trigger`, `Select.Item`, `Card.Header`, `Card.Body`) alongside convenient high-level single-component APIs.

### 4. Native Bidirectional Symmetry (LTR & RTL)
Persian and Arabic RTL layouts are first-class architectural citizens. Native pairing of **Vazirmatn** (crafted for Persian reading) and **Satoshi** (modern Latin sans-serif) ensures seamless typographic rhythm in any orientation.
