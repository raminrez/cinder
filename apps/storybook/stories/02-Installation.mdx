# Installation & Setup

Install and configure **Hashti Design System** packages in your React, Next.js, Vite, or Astro application.

---

## 1. Package Installation

Hashti is published as two modular packages:
- `@hashti/react`: Enterprise React components built on top of [React Aria Components](https://react-spectrum.adobe.com/react-aria/index.html).
- `@hashti/tokens`: Foundational design tokens, color scales, theme CSS variables, and spacing primitives.

Install both packages using your preferred package manager:

### Bun (Recommended)
```bash
bun add @hashti/react @hashti/tokens
```

### npm
```bash
npm install @hashti/react @hashti/tokens
```

### pnpm
```bash
pnpm add @hashti/react @hashti/tokens
```

### Yarn
```bash
yarn add @hashti/react @hashti/tokens
```

---

## 2. CSS Stylesheet Setup

Import Hashti's pre-compiled global stylesheet once at your application's entry point (e.g. `src/main.tsx`, `app/layout.tsx`, or `src/styles/global.css`):

```tsx
// Import Hashti styles (includes all tokens, CSS variables, and component styles)
import "@hashti/react/styles.css";
```

> **Note:** Hashti stylesheets are self-contained with zero runtime overhead. All theme variables, layer levels, and component styles are loaded in a single static stylesheet.

---

## 3. Theme Provider Setup

Wrap your application tree in the `<Theme>` provider to enable appearance theming (light/dark) and layer nesting:

```tsx
// src/App.tsx
import { Theme, Button, Card, TextField } from "@hashti/react";
import "@hashti/react/styles.css";

export default function App() {
  return (
    <Theme theme="frame-light">
      <main style={{ padding: "32px", maxWidth: "480px", margin: "0 auto" }}>
        <Card style={{ padding: "24px", display: "flex", flexDirection: "column", gap: "16px" }}>
          <h2>Entrance Gate</h2>
          <TextField
            label="Access Passkey"
            description="Enter your architectural access token"
            placeholder="e.g. hashti-auth-2026"
          />
          <div style={{ display: "flex", gap: "8px", justifyContent: "flex-end" }}>
            <Button variant="ghost">Cancel</Button>
            <Button variant="primary">Enter Portal</Button>
          </div>
        </Card>
      </main>
    </Theme>
  );
}
```

## 4. Direction & Internationalization (LTR & RTL)

Hashti is engineered with native bidirectional symmetry. To support Persian or Arabic (RTL) alongside English (LTR), configure the `dir` and `lang` attributes on your root document or layout container, and load **Vazirmatn** for optimal Persian typography:

```html
<!-- index.html -->
<head>
  <!-- Vazirmatn font for Persian/Arabic typography -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;500;600;700&display=swap" rel="stylesheet">
</head>
```

```tsx
// Example RTL Persian configuration
<html lang="fa" dir="rtl">
  <body>
    <Theme theme="frame-light" locale="fa-IR">
      {/* All drawer overlays, chevron icons, and input labels mirror automatically */}
      <App />
    </Theme>
  </body>
</html>
```

All slide-over drawers, menus, focus outlines, and navigation components dynamically adapt to the active document direction without manual style overrides.
