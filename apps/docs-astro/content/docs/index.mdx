# Hashti Design System (هشتی)

Hashti is an enterprise-grade, accessible React component library inspired by the spatial elegance and dignified hospitality of classical Persian architecture.

Built on **React Aria Components**, **Tailwind CSS v4**, and comprehensive design tokens, Hashti serves as the welcoming architectural threshold between complex underlying application logic and intuitive human experience.

## The Sacred Spatial Threshold

In classical Persian architecture — prominent across Isfahan, Yazd, Kashan, and Shiraz — the **Hashti (هشتی)** is the vaulted transitional vestibule positioned immediately behind the entrance portal (*sar-dar*). Derived from the Persian word for eight (*hasht*), it is an octagonal chamber serving as a sensory pause between the bustling street and the peaceful home.

## Core Architectural Pillars

- **Accessible**: Engineered for WCAG 2.2 AAA rigor, 7:1 minimum contrast ratios, full keyboard parity, and native screen-reader ARIA semantics.
- **Elegant**: Rooted in Persian geometric harmony, quiet surfaces, and restrained accents.
- **Open Source**: Permissive licensing, transparent engineering, community-driven evolution.
- **International**: Native dual-engine support for both LTR and RTL scripts (featuring Vazirmatn and Satoshi typography).
