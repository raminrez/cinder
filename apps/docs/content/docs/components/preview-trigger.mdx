# Preview Trigger

A **Preview Trigger** (often referred to as a **HoverCard**) is a contextual preview popover that reveals rich informational cards when a user hovers over or focuses an interactive trigger—such as a user mention `@ramin`, a link to another documentation page, an issue ticket, or an avatar.

Unlike text-only `<Tooltip>`, a Preview Trigger accommodates rich formatted content including **avatars, status badges, secondary action buttons, and live metadata**, while supporting deliberate enter/leave delays, keyboard accessibility, and pointer bridge persistence.

## Anatomy

```tsx
<PreviewTrigger delay={400} closeDelay={300}>
  <PreviewTrigger.Trigger>
    <Link href="/team/ramin">@ramin</Link>
  </PreviewTrigger.Trigger>
  <PreviewTrigger.Content>
    {/* Rich user profile preview card */}
  </PreviewTrigger.Content>
</PreviewTrigger>
```

Provide instant document summaries before users click an external or cross-section link:

```tsx

export function RichLinkPreviewExample() {
  return (

      <p>

            </span>
          </PreviewTrigger.Content>
        </PreviewTrigger>
        .
      </p>
    </div>
  );

```

### Delayed Hover & Safe Pointer Bridge

A `delay` (default 500ms) prevents unwanted flickering when users merely pass their cursor over the trigger. The `closeDelay` (default 300ms) provides a safe "pointer bridge," allowing users to move their mouse from the trigger into the popover content without the card closing abruptly:

```tsx
<PreviewTrigger delay={500} closeDelay={400} placement="bottom">
  <PreviewTrigger.Trigger>
    <button className="text-sm font-medium">Inspect Metric</button>
  </PreviewTrigger.Trigger>
  <PreviewTrigger.Content className="p-3">
    <p className="text-xs">Hover over this card without losing focus.</p>
  </PreviewTrigger.Content>
</PreviewTrigger>
```

## Props Reference

### PreviewTrigger (`PreviewTrigger.Root`)

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `isOpen` | `boolean` | — | Controlled visibility state of the preview popover. |
| `defaultOpen` | `boolean` | `false` | Default uncontrolled open state. |
| `onOpenChange` | `(isOpen: boolean) => void` | — | Callback fired when open state changes. |
| `delay` | `number` | `500` | Duration in milliseconds before popover appears upon hover. |
| `closeDelay` | `number` | `300` | Duration in milliseconds before popover closes when cursor leaves trigger and content. |
| `placement` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'bottom'` | Preferred cardinal placement relative to trigger. |
| `offset` | `number` | `8` | Distance in pixels between trigger and popover card. |
| `children` | `ReactNode` | — | Trigger element and Content popover. |

### PreviewTrigger.Trigger

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | — | The anchor element (link, button, mention) that activates the preview. |

### PreviewTrigger.Content

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `className` | `string` | — | Custom CSS classes for padding, width, and typography. |
| `children` | `ReactNode` | — | Rich interactive card layout. |

## Accessibility & Keyboard Guide

Hashti PreviewTrigger adheres strictly to **WCAG 2.1 Success Criterion 1.4.13 (Content on Hover or Focus)**:

- **Dismissable Without Moving Pointer**: Pressing <kbd>Esc</kbd> closes the preview immediately without shifting pointer position.
- **Hoverable**: Users can move their mouse pointer from the trigger into the preview card without the card disappearing.
- **Persistent**: The preview card remains visible until the user moves the hover/focus away or explicitly presses <kbd>Esc</kbd>.
- **Focus Activation**: Keyboard users focusing the trigger with <kbd>Tab</kbd> reveal the preview card automatically.
- **Role**: Emits `role="dialog"` or `role="tooltip"` with appropriate `aria-expanded` and `aria-haspopup` linkages.

## Keyboard Interactions

| Key | Action |
| :--- | :--- |
| <kbd>Tab</kbd> | Moves focus onto preview trigger element, opening card on focus. |
| <kbd>Esc</kbd> | Dismisses preview overlay card. |
