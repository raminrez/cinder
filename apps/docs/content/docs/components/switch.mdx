# Switch

Switches represent a physical toggle that allows users to instantly alternate between binary states (such as active/inactive or on/off). Unlike checkboxes — which usually queue changes until a form is submitted — switches apply changes immediately. Hashti's `Switch` is built on [React Aria Components Switch](https://react-spectrum.adobe.com/react-aria/Switch.html), providing smooth fluid animations, full keyboard accessibility, RTL layout mirroring for Persian and Arabic, and semantic color accents.

## Architectural Mechanics

In architectural engineering, a valve or physical circuit breaker changes system state the moment it is engaged. The Hashti `Switch` embodies this instantaneous causality:

```
[Off State]                             [On State]
┌─────────────────────────┐             ┌─────────────────────────┐
│  (○)       Track Off    │   ──Space─► │     Track On        (●) │
└─────────────────────────┘             └─────────────────────────┘
```

- **Immediate Effect Paradigm**: Use switches when toggling an option takes immediate effect (e.g., enabling Dark Mode, activating an SSL Proxy) without requiring a "Save" button click.
- **RTL Script Mirroring**: In Persian/Arabic (`dir="rtl"`) environments, the switch track automatically mirrors: the "off" state rests on the right and slides leftward to engage "on", honoring natural cognitive intuition.
- **Fluid Spring Transition**: The internal indicator thumb features GPU-accelerated CSS cubic-bezier transitions calibrated to Hashti motion tokens.

## Usage Examples

### Basic Usage

A binary toggle with an adjacent textual label:

```tsx
import { useState } from "react";
import { Switch } from "@hashti/react";

export function BasicSwitchDemo() {
  const [airplaneMode, setAirplaneMode] = useState(false);

  return (
    <Switch isSelected={airplaneMode} onChange={setAirplaneMode}>
      Airplane Mode
    </Switch>
  );
}
```

---

## Props Reference

`Switch` extends `RACSwitchProps` from `react-aria-components`.

| Prop              | Type                                                             | Default     | Description                                                            |
| :---------------- | :--------------------------------------------------------------- | :---------- | :--------------------------------------------------------------------- |
| `isSelected`      | `boolean`                                                        | —           | Controlled active state of the switch.                                 |
| `defaultSelected` | `boolean`                                                        | `false`     | Uncontrolled initial state.                                            |
| `onChange`        | `(isSelected: boolean) => void`                                  | —           | Callback invoked when the switch is toggled.                           |
| `size`            | `'sm' \| 'md'`                                                   | `'md'`      | Control dimensions (`sm` for tight tables, `md` standard).             |
| `color`           | `'primary' \| 'secondary' \| 'success' \| 'warning' \| 'danger'` | `'primary'` | Semantic color token for the activated track.                          |
| `isDisabled`      | `boolean`                                                        | `false`     | Whether the switch is disabled and non-interactive.                    |
| `isReadOnly`      | `boolean`                                                        | `false`     | Prevents value changes while retaining keyboard focusability.          |
| `name`            | `string`                                                         | —           | Input name attribute submitted when placed within standard HTML forms. |
| `value`           | `string`                                                         | —           | The value attribute submitted when the switch is on.                   |
| `children`        | `ReactNode`                                                      | —           | Text label or content rendered alongside the switch control.           |
| `className`       | `string`                                                         | —           | Additional CSS class names.                                            |

## Accessibility & Keyboard Interaction

Hashti switches conform to the [W3C WAI-ARIA Switch Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/switch/):

### Keyboard Interaction

- <kbd>Space</kbd>: Toggles the switch between on and off states.
- <kbd>Enter</kbd>: In forms, <kbd>Enter</kbd> submits the form rather than toggling the switch
  (standard browser behavior).
- <kbd>Tab</kbd>: Moves focus to and from the switch.

### Assistive Technology Notes

- **ARIA Role**: Renders a semantic element with `role="switch"` and `aria-checked="true"` or `"false"`.
- **Contrast**: The track and thumb maintain WCAG 2.2 AAA minimum contrast ratios in both resting off and active on states.
- **Switch vs. Checkbox**: Use a `Switch` when an action toggles on or off with immediate effect (e.g. Wifi, Dark Mode, Notification Sound). Use a `Checkbox` when the choice is part of a larger form requiring submission.
