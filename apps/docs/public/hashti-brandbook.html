01 / DUAL-DIRECTION

Native Bidirectionality

Built with CSS logical properties from the first token. Persian, Arabic, and Hebrew render with first-class optical harmony.

02 / WCAG 2.2 AAA

Rigorous Accessibility

Zero compromise on contrast ratios (≥ 7:1), keyboard focus trapping, and screen reader announcements powered by React Aria.

03 / 8-POINT HARMONY

Rooted in "Hasht"

All paddings, margins, line-heights, and container dimensions conform to an uncompromising 8pt architectural rhythm.

04 / REACT 19 HEADLESS

Zero Runtime Waste

Modern React 19 primitives with prebuilt CSS, sub-millisecond hydration, and zero runtime CSS-in-JS overhead.
