# Cinder implementation plan

## Acceptance conditions

- Reproducible Bun workspace with pinned dependencies, library exports, declarations,
  and a production documentation build.
- Carbon's official semantic tokens, component tokens, typography, spacing, motion,
  four themes, and layer aliases generated from the installed source packages.
- Styled RAC components covering Carbon's core input, selection, navigation,
  collection, feedback, overlay, and content families. Composable APIs retain RAC
  keyboard behavior, render props, refs, form validation, and controlled state.
- A distinct Cinder homepage, live four-theme specimen, searchable component
  reference, foundation reference, and working local setup instructions.
- Useful examples use the package, with clearly identified sample product data.
- Browser proof of theme inheritance through portals, keyboard interaction, form
  validation, filtering, sorting, pagination, overlay focus restoration, responsive
  layout, and automated accessibility checks.
- Source-linked research and an honest implementation/verification coverage matrix.

## Implementation order

1. **Tokens** — `packages/tokens/scripts/generate.ts`, `src/index.ts`, generated CSS
   and JSON. Compare key output values with the official packages and check every
   component CSS variable resolves.
2. **Foundation and controls** — `packages/react/src/theme.tsx`, `buttons.tsx`,
   `fields.tsx`, `selection.tsx`, `styles.css`. Preserve RAC types and state contracts;
   expose size, variant, and field anatomy conveniences.
3. **Collections and patterns** — `collections.tsx`, `overlays.tsx`, `dates.tsx`,
   `feedback.tsx`, `content.tsx`, `layout.tsx`. Keep generic collection components
   compositional and implement pagination as controlled state.
4. **Website** — `apps/docs/server.ts`, `src/`, native HTML entry. Homepage has one
   deliberate visual concept, live components and a workbench. Reference pages
   include implementation details, examples, code, keyboard notes, and sources.
5. **Distribution** — `scripts/build.ts`, `scripts/preview.ts`. Externalize React,
   RAC and dates; bundle ESM; emit declarations; package CSS and licenses; build HTML.
6. **Verification** — `tests/unit/`, `tests/browser/`, real-browser screenshots and
   design inspection at desktop, tablet, and mobile widths. Fix observed failures.
7. **Delivery** — README, package usage, component coverage, research coverage,
   verification record, and local preview.

## Boundaries

Cinder is an independent implementation. Carbon and RAC remain credited upstreams.
Core component families and their useful variants are the target; Carbon's domain
experiences, complete charting suite, and every experimental RAC feature have
separate coverage entries rather than implied support. The package names are local
workspace names until published. No registry or deployment is required to run it.

## Design decisions

The page direction is “The sentence is the layout” (seed 1403602033); the workbench
is “Framed sheet” (seed 352885001). Carbon fixes palette, type, and control geometry.
The showcase was redrawn to live controls because the real proof is interaction;
the about section to side facts because this is a system rather than a biography;
the setup section to a reading column because commands must remain selectable.
Real UI fragments supply the imagery. Cinder's name and specimen theme are the
subject of the inline hero frame.
